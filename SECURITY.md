# Security Policy

## Supported Versions

Only the latest version of the script on the `main` branch is actively supported and receives security updates or patches.

| Version | Supported |
| ------- | --------- |
| main    | ✅ Yes     |
| < 1.0.0 | ❌ No      |

## Reporting a Vulnerability

If you discover a security vulnerability (such as a DNS leak risk, command injection vectors in the script, or other system exploits), please do **not** open a public issue. Instead, report it responsibly.

You can report security vulnerabilities by emailing:
**beau.bremer@gmail.com**

Please include the following details in your report:
- A description of the issue or vector.
- Steps to reproduce or proof-of-concept (PoC) code.
- Your environment details (OS, NetworkManager version, systemd-resolved status).

We will acknowledge receipt of your report within 48 hours and work with you to patch the issue before disclosing it publicly.
